# 中文字体工程细节（口径、翻车记录、CI、字号）

## 一、两个口径，别混

```
subset  （重建口径）  只跳「整行 //」与 /* */      → 宁可多带字
check   （严格口径）  //、/* */ 全去，保留字符串  → 宁可报严
```

为什么必须拆开：重建时少一个字就是线上方框，所以宁多勿少；检查时误报只要多看一眼，
漏报就是事故，所以宁严勿宽。**用同一个口径做两件事，一定有一边是错的。**

`check_cmap.py` 的实现细节：
- `.wxml` / `.html` 去 `<!-- -->`
- `.js` / `.ts` / `.vue` 走去注释状态机（**不能**用 `re.sub(r'//.*')`，会把 `'https://…'` 截断）
- `.json` 全算（`navigationBarTitleText` 这类会显示）
- `.css` / `.wxss` 不算（只有类名和注释）
- `test*.js` 默认不算（进不了线上包），但**它的断言文案确实含中文** → 需要时 `--include-tests`

## 二、真实翻车记录

1. **数量检查的假绿灯**：脚本报「代码用到 871 个汉字 / 字表 878 个 ✓ 没有缺字」，
   真机仍有 7 个字（临 / 插 / 教 / 解 / 讲 / 陆 / 骤）显示成方框 —— 全部来自刚合进来的两个新页面。
   根因：只比数量，没比 cmap。
2. **行尾注释**：在两行代码后补了 `// … 不显示重量栏`，`栏`、`省` 立刻被报缺字。
   同一天还因为行尾注释带进 `轴 / 栏 / 缘 / 齐`，重建后 348 → 350 KB / 896 汉字。
3. **测试断言**：`ok('… 精简 / 命中 / 齐')` 三次报缺，全部来自 `test-page.js` 的断言文字，与 UI 无关。
4. **灌表格数据**：把动作库表的肌群列灌进详情页，一次报缺 15 字。
5. **顺序错**：先合字体 PR（修 7 字），再合另一个带文案的 PR（又带进 3 字），白做一轮。
   铁律：**字体 PR 最后单独合**。

## 三、判断「缺字是不是我引入的」

一条命令，别凭记忆：

```bash
git stash -q && python3.12 scripts/check_cmap.py ./app --fonts app/data/fonts.js ; git stash pop -q
```

- 改前就红 → 前人留下的，别默默重建盖过去（先确认为什么能上线）
- 改前是绿的 → 你新加的，重建子集

## 四、CI / pre-commit 接法

```yaml
# .github/workflows/fonts.yml 片段
- name: 字体缺字检查
  run: |
    python -m pip install fonttools brotli
    python scripts/check_cmap.py ./app --fonts app/data/fonts.js --var ZH
```

`exit 1` 就是红，不需要额外解析输出。

pre-commit 版本（只跑检查，不重建 —— 重建产物几十万字符，不该在每此提交时改）：

```yaml
- repo: local
  hooks:
    - id: cjk-missing-glyph
      name: 中文字体缺字检查
      entry: python scripts/check_cmap.py ./app --fonts app/data/fonts.js
      language: system
      pass_filenames: false
```

## 五、体积账

| 项目 | 数值 |
|---|---|
| Noto Sans SC 可变字体全量 | 16.9 MB |
| 995 汉字子集 woff2 | 275 KB |
| 同上一份 base64 内联后 | ≈ 367 KB（× 4/3） |
| 项目里常见值（含标点/ASCII/保险字） | 350–400 KB |

base64 膨胀是固定的 4/3，**先算子集体积再决定内联还是外链**：
- 小于 ~400 KB base64：直接内联，最简单、无网络依赖
- 大于 ~1 MB：改用外链 `https://` + 合法域名白名单（小程序要配 `downloadFile` 白名单），
  或者拆成两档字重、或减少文案里的生僻字

## 六、字号与可读性（子集化之后最常见的返工）

用户说「字太小」时，不要一处一处调 `font-size`：

1. **只认一套 token**：`app.wxss` / `:root` 里定义 8 档（`--fs-1 … --fs-8`），全项目只用变量。
   `grep -rn "font-size:[0-9]" app/pages` 应该只剩 token 定义那几行。
2. **中文有硬下限**：移动端正文 ≥ `32rpx`（≈16px @375）、辅助说明 ≥ `24rpx`。
   10px 的浅灰小字在真机上不是说明，是装饰。
3. **调完必须查折行**：字号 +1 档常让「标题 + 单位/按钮」挤成两行，卡片高度跳变、列表参差。
   判据：拿最小屏（375×667）截图，量卡片高度是否一致。
4. **单位要长在刻度上**，不要另起一行小字。纵轴直接写 `50 组`（顶端刻度带单位、其余档只给数字），
   比在轴下补一行「每周完成 · 组」有效十倍 —— 实测那行小字用户根本看不见。

## 七、授权

| 字体 | 许可 | 能商用/再分发 |
|---|---|---|
| Noto Sans SC / 思源黑体 | SIL OFL 1.1 | ✅ 可商用、可子集化、可内联 |
| 苹方 / 微软雅黑 / 思源以外的系统字体 | 各自商业许可 | ❌ 不能随包分发（子集化也算分发） |
| 来路不明的「免费字体」 | 不明 | ⚠️ 风险自负，别用在商业项目 |

子集化**不改变授权**：切出来的仍然是该字体的衍生，微软雅黑子集照样不能分发。
